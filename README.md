# 卡西欧计算器

免费 Android 10+ 的 fx-991CN X 模拟器，支持离线计算、状态保存和四种配色。

[下载 APK](https://github.com/Antssos/CASIO_991_CNX/releases/download/fx991cnx-v0.7.0-preview/fx991cnx-arm64-release.apk)

内置固件，安装后即可离线使用。

按 **SHIFT → MENU**，翻到设置末页：

- **3：主题** — 蓝、白、粉、黑。
- **4：按键** — 震动强度、按键音量，均可选关、轻、中、重。

设置自动保存，`DEL` 返回上一级。
