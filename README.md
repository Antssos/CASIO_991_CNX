# fx-991CN X Emulator · 0.3.0-preview

Android 10+ 原机模拟器，C++ nX-U8 核心 + NDK/JNI + 原生 Android 界面。没有网页、服务器、广告、账户或网络权限。**APK 不含 Casio ROM，首次需要自行导入。**

## 下载与安装

[下载 Release](https://github.com/Antssos/cloudcodex/releases/tag/fx991cnx-v0.3.0-preview)，安装 `fx991cnx-arm64-release.apk`。仓库为私有，下载需登录有权限的 GitHub 账户；安装后的应用不需要账户。

首次点液晶屏，选择您有权使用的 fx-991CN X 完整 256 KiB ROM。文件仅复制到应用内部，之后离线使用，无需再次选择。支持已测试样本的精确指纹识别；未知版本需确认机型，不支持将 ES、EX 或 CW 固件转换为 CN X。

## 四套主题与设置

按用户提供的四张真机图调整机身、左侧品牌区、右侧太阳能板、下沉 LCD、四瓣方向键、键帽与标注：

- 雾霾蓝：浅蓝机身、蓝色数字键、浅色功能键、浅杏色 DEL/AC。
- 珍珠白：暖白机身与白色键帽，深灰文字。
- 樱花粉：粉色机身与深粉数字键，浅杏色 DEL/AC。
- 经典黑：碳纹机身、银色圆键、白色数字键、蓝色 DEL/AC。

点右上角 **设置**（或长按机身顶部）即可选择主题、开关震动、调整三档震动强度、开关按键音及调整音量。设置自动保存，重新打开仍保留。默认经典黑、轻震动开启、按键音关闭；静音和振动模式下不播放按键音。

原机 MENU/SHIFT→MENU 仍交给固件处理，应用设置不占用原机按键。ROM 更换、清除计算器状态和许可证也在设置中；清除计算器状态不会重置主题和声音偏好。

四套静态素材预览在 [docs/theme-previews](docs/theme-previews)。**这些是面板素材预览，不是 Android 运行截图。** 素材为代码绘制，机身与键帽上所有文字均为矢量轮廓，数字、计算符号和定积分图案另外绘制，未复制商品照片像素；与照片的光照、曲面、真实材质及部分印刷细节仍有差异，不宣称“像素级完美 1:1”。

## 使用与验证范围

50 个按键共用绘制和触摸坐标来源，LCD 主区为真实 192×63 点阵。计算、中文菜单、变量和历史均由导入固件执行，没有替代科学计算引擎。退出和后台时保存 CPU、RAM、LCD 及外设状态，前台也定期保存；按 ROM SHA-256 隔离并用 CRC 校验。

指定 ROM 在原生 C++ 核心中已实际计算 `10×0.25÷(10+2.5)=1/5`、S⇔D=0.2、9+√2、矩阵乘法及二次方程根 3/2。**按用户最新要求，本轮没有执行 Android 运行或自动测试，新增主题、声音与震动由用户安装验收。** 详情见 [TEST_REPORT.md](TEST_REPORT.md)。

仅申请 `VIBRATE` 普通权限，用于用户可关闭的按键震动；没有网络、存储、账户或录音权限。按键音为本项目合成的短音效，不使用麦克风或网络。
