# 卡西欧计算器 · 0.6.0-preview

Android 10+ 原机模拟器，C++ nX-U8 核心 + NDK/JNI + 原生 Android 界面。没有网页、服务器、广告、账户或网络权限。**APK 不含 Casio ROM，首次需要自行导入。**

## 下载与安装

[下载 Release](https://github.com/Antssos/CASIO_991_CNX/releases/tag/fx991cnx-v0.6.0-preview)，安装 `fx991cnx-arm64-release.apk`。仓库公开，下载和使用应用均无需账户。

首次点液晶屏，选择您有权使用的 fx-991CN X 完整 256 KiB ROM。文件仅复制到应用内部，之后离线使用，无需再次选择。支持已测试样本的精确指纹识别；未知版本需确认机型，不支持将 ES、EX 或 CW 固件转换为 CN X。

## 四套主题与设置

按用户提供的四张真机图调整机身、左侧品牌区、右侧太阳能板、下沉 LCD、四瓣方向键、键帽与标注：

- 雾霾蓝：浅蓝机身、蓝色数字键、浅色功能键、浅杏色 DEL/AC。
- 珍珠白：暖白机身与白色键帽，深灰文字。
- 樱花粉：粉色机身与深粉数字键，浅杏色 DEL/AC。
- 经典黑：碳纹机身、银色圆键、白色数字键、蓝色 DEL/AC。

整台计算器占满屏幕，隐藏状态栏、导航栏及外部设置栏。不同屏幕比例会对机身宽高做适配，热区使用同一变换；从屏幕边缘滑动可临时显示系统导航。

按 **SHIFT → MENU** 直接进入固件原有的中文 SETUP。往下翻到末页：

```text
1:语言
2:对比度
3:主题
4:按键
```

前两项和原有 SETUP 操作继续由固件执行。主题有蓝、白、粉、黑四种；按键目录只保留 **1:震动强度、2:按键音量**。这两项均用数字选择：**1:关、2:轻、3:中、4:重**。音量对应静音、20%、50%、85%；震动对应关闭和三档强度。不显示当前档位、星号或额外的设置首页，“关于”已移除。

主题选择后返回末页，强度/音量选择后返回按键目录；`DEL` / `MENU` 返回上一级，`AC` / `ON` 关闭扩展并交给原机处理。设置立即保存。默认经典黑、轻震动开启、按键音关闭；静音或振动模式下不播放按键音。

应用只在识别到原机“语言／对比度”页时补写空白两行，不替换原机设置、不修改 ROM。不相关页面及计算输入的 3、4 键照常发送给固件。当前匹配的是已验证中文固件的显示标签；其他固件或语言下可能不显示扩展入口，仍可使用原机 SETUP。尚未导入 ROM 时点击 LCD 导入，扩展设置需原机页面启动后使用。

安卓桌面显示名为 **卡西欧计算器**，采用用户审定的图 1：鼠尾草绿／米白 C、%、＝ 极简图标，方形浅暖灰底，不预先裁圆角。自适应前景四边各收进 3%，在常见 72dp 图标视口中，主体约占宽高的 68%，浅色留白比桌面合成预览更窄；最终圆角/圆形遮罩由启动器决定。

四套静态素材预览在 [docs/theme-previews](docs/theme-previews)。**这些是面板素材预览，不是 Android 运行截图。** 素材为代码绘制，机身与键帽上所有文字均为矢量轮廓，数字、计算符号和定积分图案另外绘制，未复制商品照片像素；与照片的光照、曲面、真实材质及部分印刷细节仍有差异，不宣称“像素级完美 1:1”。

## 使用与验证范围

50 个按键共用绘制和触摸坐标来源，LCD 主区为真实 192×63 点阵。计算、原机中文菜单、变量和历史均由导入固件执行，没有替代科学计算引擎。退出和后台时保存 CPU、RAM、LCD 及外设状态，前台也定期保存；按 ROM SHA-256 隔离并用 CRC 校验。

指定 ROM 在原生 C++ 核心中已实际计算 `10×0.25÷(10+2.5)=1/5`、S⇔D=0.2、9+√2、矩阵乘法及二次方程根 3/2。**按用户最新要求，本轮没有执行 Android 运行或自动测试，本次图标比例和桌面显示由用户安装验收。** 详情见 [TEST_REPORT.md](TEST_REPORT.md)。

仅申请 `VIBRATE` 普通权限，用于用户可关闭的按键震动；没有网络、存储、账户或录音权限。按键音为本项目合成的短音效，不使用麦克风或网络。

当前为开发签名预览版，不同构建可能无法覆盖安装，届时需卸载重装。卸载或清除应用数据会删除导入 ROM、状态与偏好设置，请保留自己的原始 ROM 文件。
